프런트엔드 팀원 세 명이 천줄짜리 HTML 코드를 작성하게 된다면, 문제점이 발생할 수 있다. 이에 대한 해결책으로 컴포넌트로 나누는 방법이 있다. 즉, 코드를 파일별로 나눠서 각 팀원이 따로 개발하는 방식이 적합하다. 이와 관련하여, 자바스크립트를 활용하여 컴포넌트 또는 구성 요소 부품을 만들 수 있으며, 이를 통해 코드의 재사용성과 모듈화가 이루어진다. 하지만, 리액트의 경우, 스패츠라는 도구를 검색하면 다양한 단축어를 만들 수 있어, 개발 효율성을 더욱 높일 수 있다. 이러한 접근은 개발 과정에서 중복된 코드 작성을 줄이고, 유지보수의 용이성을 증가시키는 데 중요한 역할을 한다.

비동기 처리

장의: 특정 코드의 연산이 끝날 때까지 코드의 실행을 멈추지 않고, 다음 코드를 먼저 실행하는 방식. 즉, 하나의 작업이 완료되기를 기다리지 않고 동시에 다른 작업을 수행할 수 있도록 하는 프로그래밍 기법

주요 기능 및 활용:
1. 네트워크 요청 (API 통신): 서버에서 데이터를 가져오거나 보낼 때 가장 많이 사용. (예: fetch, axios 사용)
2. 타이머 및 지연 작업: 특정 시간 이후에 코드를 실행할 때 사용. (예: setTimeout, setInterval)
3. 파일 입출력 (I/O): 로컬 저장소에서 큰 파일을 읽거나 쓸 때 애플리케이션이 멈추는 것을 방지.
4. 사용자 인터페이스(UI) 응답성 유지: 무거운 연산을 처리하는 동안에도 브라우저 화면이 멈추지 않고 사용자의 클릭이나 스크롤에 반응할 수 있게 해줌.

커스텀 훅 (Custom Hooks)

사용 목적 및 방법: 컴포넌트 간에 중복되는 상태(State) 관리나 생명주기(Lifecycle) 로직을 추출하여 재사용 가능한 함수로 만드는 기능
권장사항:
1. 반드시 use로 시작할 것
2. 단일 책임 원칙 유지
3. 순수 자바스크립트 로직 분리
4. 과도한 추상화 지양
5. 의존성 배열 관리
