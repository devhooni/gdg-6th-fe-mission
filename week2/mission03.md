리액트 훅은 함수형 컴포넌트에서도 상태를 관리하거나 생명주기에 관여할 수 있게 해주는 도구인데, 여기서 특정 로직이 반복될 때 이를 따로 빼내어 만든 것이 바로 커스텀 훅이다. 커스텀 훅을 쓰면 복잡한 로직을 마치 부품처럼 갈아 끼울 수 있어 코드가 훨씬 깔끔해진다. 특히 API를 호출하는 비동기 처리는 화면이 렌더링된 후 실행되어야 하기에 주로 useEffect 같은 훅 안에서 다뤄지며, 데이터를 가져오는 동안의 로딩 상태나 에러 처리를 얼마나 매끄럽게 하느냐가 사용자 경험의 핵심이 된다. 마지막으로 리액트 라우팅은 브라우저의 주소창과 컴포넌트를 연결해 주는 역할을 하는데, 덕분에 페이지 전체를 새로고침하지 않고도 마치 여러 페이지가 있는 것처럼 매끄럽게 화면을 전환하며 애플리케이션의 뼈대를 완성하게 된다.
