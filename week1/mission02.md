1. 반응형 레이아웃 (Responsive Layout): 사용자의 화면 크기(스마트폰, 태블릿, 데스크탑 등)에 맞춰 웹 페이지의 디자인이 유동적으로 변하는 기술이다.

특징: 주로 CSS의 미디어 쿼리(@media)를 사용하여 디바이스의 너비에 따라 레이아웃(Flex, Grid 등)과 폰트 크기를 조절해 모든 기기에서 최적화된 화면을 제공한다.

2. Bootstrap (부트스트랩): 가장 널리 사용되는 오픈소스 프론트엔드 프레임워크다.

특징: 버튼, 폼, 내비게이션 등 미리 디자인된 CSS/JS 컴포넌트들을 제공한다. 클래스 이름만 추가하면 빠르고 일관된 디자인의 반응형 웹을 뚝딱 만들 수 있어 개발 속도를 크게 높여준다.

3. MongoDB (몽고디비): 대표적인 NoSQL 데이터베이스다.

특징: 전통적인 관계형 데이터베이스(표 형태)와 달리, 데이터를 JSON과 유사한 문서(Document) 형태로 저장한다. 데이터 구조(스키마)가 유연하여 개발이 빠르고, 대용량 데이터를 처리하거나 시스템을 확장하는 데 유리하다.

4. TypeScript (타입스크립트): 마이크로소프트에서 개발한 JavaScript의 상위 집합(Superset) 언어다.

특징: 자바스크립트에 정적 타입(Static Typing)을 추가했다. 변수나 함수가 어떤 형태의 데이터(문자, 숫자 등)를 가질지 미리 지정하여, 코드를 실행하기 전(컴파일 단계)에 오류를 잡아내고 코드의 안정성과 예측 가능성을 높여준다.
