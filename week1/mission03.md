리액트(React)는 메타(Meta, 구 페이스북)에서 개발한 오픈소스 자바스크립트 라이브러리로, 사용자 인터페이스(UI)를 구축하는 데 사용된다. 주로 화면 깜빡임 없이 부드럽게 동작하는 싱글 페이지 애플리케이션(SPA) 개발에 널리 쓰이며, 다음과 같은 핵심 특징들을 가지고 있다.

1. 컴포넌트 기반 (Component-Based)
   UI를 독립적이고 재사용 가능한 조그만 조각인 '컴포넌트'로 나누어 개발한다. 헤더, 버튼, 목록 등을 각각의 레고 블록처럼 만들어 조립하듯 화면을 구성하므로, 코드의 재사용성이 높고 유지보수가 매우 쉽다.

2. 가상 돔 (Virtual DOM)
   데이터가 변경될 때마다 브라우저 화면 전체를 다시 그리면 성능이 크게 저하된다. 리액트는 메모리상에 존재하는 가짜 DOM(가상 돔)에 먼저 렌더링을 진행한 뒤, 이전 상태와 비교하여 실제 변경된 부분만 찾아내어 진짜 화면(DOM)에 업데이트한다. 이 덕분에 렌더링 성능과 속도가 비약적으로 향상된다.

3. JSX (JavaScript XML) 문법
   자바스크립트 코드 안에서 HTML과 유사한 마크업 문법을 작성할 수 있게 해주는 확장 문법이다. 화면의 뼈대를 구성하는 마크업과 동작을 제어하는 자바스크립트 로직을 하나의 파일에서 직관적으로 파악할 수 있어 개발 편의성이 높다.

4. 단방향 데이터 흐름 (Unidirectional Data Flow)
   데이터가 항상 부모 컴포넌트에서 자식 컴포넌트로, 즉 위에서 아래로만 흐른다. 여러 컴포넌트가 얽혀 있는 복잡한 앱에서도 데이터가 어디서 어떻게 변했는지 추적하기 쉬워 앱의 안정성이 높아진다.

5. 방대한 생태계와 뛰어난 확장성
   리액트 자체는 UI를 그리는 뷰(View) 역할만 담당하는 가벼운 라이브러리다. 하지만 전 세계에서 가장 인기가 많아 화면 이동(React Router), 상태 관리(Redux, Zustand 등)를 위한 유용한 확장 도구들이 무수히 많다. 또한, 리액트의 기본 원리만 알면 리액트 네이티브(React Native)를 통해 스마트폰 앱(iOS, 안드로이드)까지 개발할 수 있다.
